ARCHITECTURE LESSON

Lab A · TurfBot interactive investigation

01

Open TurfBot

Visit http://localhost:8120 and sign in as a user with appropriate Keycloak module roles.

02

Ask an ERP question

Example: “Which inventory items are below reorder point?”

03

Inspect the execution

Observe streaming text and the lookup chips with tool name, duration and row count.

04

Check role separation

Ask a racing-specific question as an accounting-only user; the tool must not be available.

05

Review audit evidence

As TC_ADMIN or TC_AUDITOR, inspect /usage and conversation details.

ARCHITECTURE LESSON

Lab B · Rex replenishment

01

Open Workforce

Visit http://localhost:8121; use a permitted inventory/buyer role.

02

Inspect roster

Locate Rex and read the declared permissions, autonomy and schedule.

03

Initiate a controlled run

Observe low-stock facts and a proposed purchase requisition.

04

Check manager inbox

If approval is required, inspect action quantity, cost, evidence and reasons.

05

Follow the result

Review run activity and procurement requisition in the ERP.

ARCHITECTURE LESSON

Lab C · Cleo collections

01

Review overdue balances

Use AR ageing data and Cleo’s employee page.

02

Observe stage selection

A reminder, second notice or final notice arises from defined overdue rules.

03

Review approval

An AR manager inspects final notices or account-hold actions.

04

Confirm outcome

Inspect notice documents, run activity and customer state only where authorized.
