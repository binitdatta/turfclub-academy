ARCHITECTURE LESSON

Trace one user request

01

Request arrives

Browser posts a question; Flask checks the authenticated session.

02

Select the toolbox

The accessible ERP tool list is computed from Keycloak-derived roles.

03

Claude plans a lookup

The model issues JSON-schema tool calls and the graph routes execution.

04

Tool queries an API

The executor uses the chatbot service identity to call permitted GET endpoints.

05

Tool results become context

The model receives a bounded result set and may request another lookup.

06

Stream and account

Final text streams to the browser; MySQL records usage, tool rows and cost.
