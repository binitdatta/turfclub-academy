ARCHITECTURE LESSON

Why a graph?

Agent node

Sends the conversation, system prompt and bound tool definitions to Claude; streams text and accounts for usage.

Tools node

Executes requested lookups, logs each result and returns ToolMessage objects; graph cycles back to the agent until an answer or configured limit.

chatbot/turfbot/agent/graph.py

build_graph() defines START → agent → tools → agent; a conditional edge ends the run when the model no longer requests tools.

chatbot/turfbot/agent/tools.py

Registry and tools_for(roles) determine which of the 56 ERP lookup tools the user is permitted to use.

SECURITY BY DESIGN

Architecture boundaries

TurfBot uses read-only GET calls; direct database access to the ERP module schemas is not part of its lookup path. The chatbot schema is for conversations, usage and audit.
