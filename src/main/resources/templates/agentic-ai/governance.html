ARCHITECTURE LESSON

Trust boundaries that matter

01

Authentication

Humans sign in through Keycloak OIDC/PKCE; AI employees use distinct confidential OAuth clients.

02

Authorization

Roles determine both the tools a model can see and the ERP REST actions a client can execute.

03

Input grounding

Facts come from ERP GET operations; the model is not trusted to invent financial quantities.

04

Deterministic business policy

Python code classifies an action AUTO / APPROVAL / SKIP before execution.

05

Human oversight

An authorized buyer or AR manager can inspect, edit, approve or reject a proposal.

06

Audit and resilience

Log decisions, token usage and outcomes; persist checkpoints and use locks to avoid duplicate resumes.
